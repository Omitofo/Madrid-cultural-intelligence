# Findings

This is the evidence layer: what was found when checking entities or researching a question.

Unlike entity records, findings are time-sensitive and should preserve the date and sources used.

## Folders and files

- `events/`: individual upcoming or recently announced events.
- `calendar.md`: living index of event findings, grouped by date, with links to the detailed records.
- `schedule_checks/`: dated notes describing which entity calendars were checked and what was found.
- `entity_discoveries/`: short research notes on newly discovered entities before or alongside adding a formal entity record.
