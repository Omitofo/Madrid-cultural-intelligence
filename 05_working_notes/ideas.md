# Ideas

A parking lot for possible improvements. Do not implement these until there is a practical need.

- Add a lightweight subject vocabulary if filtering across many entities becomes difficult.
- Add a simple index of entities by topic if the number of records grows substantially.
- Consider a permanent event archive only if dated findings become difficult to search.
- Consider a recurring schedule-check workflow once the manual research process is stable.
- Consider linking selected events to a calendar through a connected calendar tool; keep calendar actions separate from repository storage.
