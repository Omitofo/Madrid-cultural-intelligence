# Entities

This directory contains concise reference records for sources worth revisiting.

An entity may be an institution, organization, venue or discovery source. Records should help an LLM answer: **what is this, why follow it, and where should I check for current activity?**

Use `TEMPLATE.md` when creating a record.

## Categories

- `institutions/`: academies, universities, foundations and established institutions.
- `organizations/`: associations, societies, organizers and groups.
- `venues/`: physical spaces that host activities.
- `discovery_sources/`: calendars, directories, newsletters and aggregators.

The initial records are seed entries. Their details and event policies should be verified against official sources before relying on them.
